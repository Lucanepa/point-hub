      Hall internet
      Checking the internet…

      The hall's free Wi-Fi lets the board onto the internet only after a login with a code by SMS, and the login lasts about a day. Live scoring, the club schedule and the board's clock need it; the scoreboard itself does not. Type your own mobile number — it is used for this login only and is not saved on the board.

      Board feedback
      Countdowns

      Timing, allowances, blink and match format are set per sport.

      Display

      How bright the LED panel drives. 0 turns the panel off to save power — the controller stays reachable, so set any value above 0 to switch it back on. 5–100 is on; the panel blinks for about a second while it restarts at the new level.

      Match format

      Best-of decides how many sets win the match. Timeouts go red at the total; subs go amber one short and red at the total. The name sizes are scoreboard ceilings — a long name still shrinks to clear the set counter, so these mainly decide how big a SHORT name gets. One per side, and each name row on the Game tab has its own −/+ that applies straight away. Left and right are panel halves, so they stay put when you swap ends.

      Crest screen

      The pre-match screen beside the crest. Long names are shrunk automatically to fit the panel, so this size is the ceiling — what a short name like KSCW gets. Turn the switch off to show short codes instead.

      Board identity

      Branding sets the idle / crest screen — KSC Wiedikon shows the club crest, Plain shows the team names only. Live scoring publishes the running score to the public /live page. With the scorer behind the board, the Game tab's team cards are swapped to match what the scorer sees — the team on your left is the one on the panel's right. The preview under them always shows the panel as the court sees it.

      Schedule

      An hour before a home game on the club's schedule, the board puts both names up at 0–0 and keeps showing the clock — the same as tapping the game on the Link tab. It never touches a match that is being scored, and a game you dismissed stays dismissed. Needs the board's clock, so it waits until the board has been online once.

      Club

      For the club logo / idle screen — available once the board accepts an image upload. Countdowns now use fixed labels (TO ·, INTERVAL, WARM UP).

      Access

      Set a digits-only PIN so only your scorer can change the score — anyone who scans the board can still watch, not touch. Leave blank to keep the current PIN.

      Diagnostics

      Everything the board does — board writes, relay traffic, every scoring action, settings changes and errors — is recorded and live-viewable. Open this first when something looks wrong; it is also what to send with a bug report.
