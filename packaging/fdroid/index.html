Point Hub

The console of the LedBox scoreboard, for the scorer's table. By KSC Wiedikon.

Android tablet

The tablet at the board updates Point Hub from the board by itself. For a new tablet, use F-Droid: add this repository once, then install Point Hub from it.

Add to F-Droid APK @APK_VERSION@

Repository: @REPO_URL@

Fingerprint: @FINGERPRINT@

Windows

The .msi from the latest release, or Scoop:

scoop bucket add point-hub https://github.com/Lucanepa/point-hub
scoop install point-hub/point-hub

macOS

The .dmg for your Mac from the latest release (arm64 = Apple silicon), or Homebrew:

brew tap lucanepa/point-hub https://github.com/Lucanepa/point-hub
brew install --cask lucanepa/point-hub/point-hub

Point Hub is not notarized by Apple: the first time, open it, then System Settings > Privacy & Security > Open Anyway.

Linux

The .deb (Debian, Ubuntu) or .rpm (Fedora) from the latest release. Point Hub does not update itself: install each new version over the old one.
